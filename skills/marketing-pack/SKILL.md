# Marketing pack

[coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
at `5b2c0007`. MIT. Playbooks at `skills/marketing/<name>/SKILL.md`.
The rest of that repo is not installed.

| Ask | Playbook |
| --- | --- |
| Write the page or the message | `copywriting` |
| Edit copy that already exists | `copy-editing` |
| What the site should say, and where | `content-strategy` |
| Technical and on-page SEO | `seo-audit` |
| SEO for pages an agent will generate | `ai-seo`, `programmatic-seo` |
| Ship a launch | `launch` |
| Price, or the pricing page | `pricing` |
| First-run and activation | `onboarding` |
| The page does not convert | `cro` |
| Paid acquisition | `ads` |
| Social posts | `social` |
| A referral loop | `referrals` |
| The community, not the campaign | `community-marketing` |
| A piece of content, produced | `content-strategy`, then `skills/content/content-creator/` |

`content-creator` is [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills)
at `19392f7a`, MIT, not part of the Corey tree.

Cold email, prospecting, and sales enablement live in this same folder.
They are `sales-pack`, not a marketing campaign.

One playbook per turn. A PRD is `product-pack`. Influencer work is not
installed. Say so.

If `skills/marketing/` is missing, tell the owner to run
`scripts/install-skills.sh` (Windows: `install-skills.ps1`).
