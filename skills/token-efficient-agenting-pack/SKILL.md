# Token-efficient agenting pack

This is a local Cat Paw adaptation of selected concepts audited in [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) at the exact audited commit `2fd153c67988e980fb0b2455c90832159a6a5a25`. The source repository's skill material is audited only where the concepts are MIT licensed. The license and scope caveat is important: this local adaptation uses no BSL runtime, service, binary, proxy, or gateway from the source project, and it does not copy upstream prose. The commit is an audit reference, not a bundled runtime.

Read this router and choose exactly one child for the turn. Do not combine inventory, compression testing, and migration into a single procedure.

| Request | One child playbook |
| --- | --- |
| Find and label model-call sites before changing anything | `llm-callsite-inventory-and-labeling` |
| Test whether shorter instructions preserve safety and behavior | `agent-instruction-compression-safety-test` |
| Move context between agents or models without losing evidence | `reversible-agent-context-migration` |

## Measurement and boundary rules

Every result must say whether it is **measured**, **inferred**, or **unavailable**. No unmeasured savings claims. Do not claim token or cost savings from a proxy estimate alone. This pack has no proxy, gateway, telemetry, cookies, paid calls, hosted mode, or hidden credential discovery. It never adds a dependency or changes runtime configuration automatically.

Use chat for an inventory or tabletop comparison. A private repository, device, browser, or durable artifact requires `target-workspace` and `plow-latch`, owner permission, and a path under `~/CatPaw/workspaces/<slug>/` on the owner's computer. Keep the OpenClaw container as reasoning space only. If a child cannot measure a claim, say so and stop; do not manufacture a benchmark.
