# Product pack

[phuryn/pm-skills](https://github.com/phuryn/pm-skills) at `8607e3b0`. MIT.
Cloned to `skills/product/<plugin>/<skill>/SKILL.md`.

Open the plugin that owns the ask, then one skill. Do not tour the tree.

| Plugin | Reach for it when |
| --- | --- |
| `pm-product-discovery` | The problem is still fuzzy |
| `pm-market-research` | The market, the user, or the competitor is the question |
| `pm-execution` | PRD, stories, OKRs, sprint, roadmap, premortem, priority |
| `pm-product-strategy` | The bet, the segment, the outcome |
| `pm-go-to-market` | Beachhead, battlecard, growth loop |
| `pm-marketing-growth` | Launch motion owned by product, not a copy pass |
| `pm-data-analytics` | A/B, cohort, a query that decides |
| `pm-ai-shipping` | What shipped versus what was intended |
| `pm-toolkit` | A small artifact the other plugins assume |

Entry points inside `pm-execution`: `create-prd`, `user-stories`,
`job-stories`, `brainstorm-okrs`, `outcome-roadmap`,
`prioritization-frameworks`, `pre-mortem`, `sprint-plan`.

Idea validation, an MVP cut, and a price are product work. Do them with
the discovery, execution, and go-to-market playbooks above.
`slavingia/skills` has no license, so those files are not installed and
must not be quoted.

A marketing sentence (headline, SEO, onboarding copy) is `marketing-pack`,
not this tree. A paper is `academic-research-pack`.
