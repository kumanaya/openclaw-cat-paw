# Design pack

Two MIT trees. Open one playbook. Build on Latch, in the repo the owner
named, not in the OpenClaw container.

## Emil Kowalski — `skills/design/emilkowalski/`

[emilkowalski/skills](https://github.com/emilkowalski/skills) at `85e8e236`.

| Ask | Playbook |
| --- | --- |
| Add motion | `animate` |
| Motion in Expo | `animate-expo` |
| Name the motion before you invent one | `animation-vocabulary` |
| Find where motion belongs | `find-animation-opportunities` |
| The motion is already there and weak | `improve-animations` |
| Review motion | `review-animations` |
| Apple platforms, the HIG | `apple-design` |
| A native mobile screen | `mobile-native` |
| Which component library | `pick-ui-library` |
| A throwaway UI | `prototype` |
| Swift | `write-swift` |
| His design-engineering bar | `emil-design-eng` |
| Sonner / toasts | `ask-sonner` |

## UI baseline — `skills/design/ui-skills/`

[ibelick/ui-skills](https://github.com/ibelick/ui-skills) at `b1cc8e00`.

`baseline-ui`, `improve-ui`, `fixing-accessibility`,
`fixing-metadata`, `fixing-motion-performance`, `create-design-md`.

Reach for this tree when the screen is wrong in structure, contrast,
metadata, or jank. Reach for Emil when the question is the motion itself.

A marketing headline is `marketing-pack`. A security review of the page
is `change-review` or `cybersecurity-pack`, not a visual pass.
