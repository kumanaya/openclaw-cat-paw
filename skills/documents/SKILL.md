# Documents

The owner asked for a file, not a description of a file.

Anthropic's `pdf`, `docx`, `pptx`, and `xlsx` skills are source-available,
not open source. They are not installed. Do not follow them from memory
and do not claim you did.

1. Agree the artifact: kind, audience, and the one directory it belongs in.
   Engagement evidence goes to `~/CatPaw/workspaces/<slug>/` on the Latch
   computer (`target-workspace`). Anything else the owner asked to keep
   goes where they named. Not the OpenClaw container.
2. Produce the file with tools already on that computer, through Latch,
   after approval. A spreadsheet is a real workbook. A deck is a real
   deck. A memo can be Markdown only when they asked for Markdown.
3. Open or read the file back in the same turn and report the path.
   A path you did not write is not done.

Charts, speaker notes, and a second format wait until they ask.
A paper with citations is `academic-research-pack`, then this skill only
for the file format.
